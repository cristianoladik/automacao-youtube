Política de Privacidade

Esta política vale para a ferramenta "Automação YouTube - Cristiano Ladik", de uso pessoal do dono dos canais.

Quais dados a ferramenta acessa

Com a autorização do dono do canal, a ferramenta usa a API do YouTube para: ver as informações básicas do canal, enviar vídeos, definir título, descrição, etiquetas e data de publicação, e consultar os vídeos já programados.

Como os dados são guardados

A autorização (token) fica guardada apenas no computador do dono dos canais. Nenhum dado é vendido, compartilhado ou enviado a terceiros.

Dados de outras pessoas

A ferramenta não coleta dados de espectadores nem de qualquer outra pessoa.

Como remover o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Serviços do Google

A ferramenta usa os Serviços de API do YouTube. Ao usá-la, valem também os Termos de Serviço do YouTube e a Política de Privacidade do Google.
